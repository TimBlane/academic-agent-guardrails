# 支柱四：严谨学术范式与去营销化规范 (Academic Rigor & Anti-Hyperbole)

## 痛点背景
受互联网广告与非学术语料影响，LLM 极易输出缺乏同行评审克制感的夸张表达、没有物理依据的类比修辞，或将未经专门仪器测量的主观感受写入论文/PPT，同时习惯于把支持信息（SI）长篇推导堆满投影屏幕。

---

## 核心学术禁令

### 1. 反营销夸大、反臆造类比与反未测感官词
- **禁用商业与极端化词汇**：坚决禁止“军工级”、“工业级”、“神级”、“颠覆性”、“革命性”、“顶尖”、“第一梯队”、“彻底杜绝”、“彻底终止”、“断崖式”、“白炽”、“暴力”等词汇；
- **禁用无物理依据的臆造类比**：严禁编造“避雷针效应”、“活塞式”等原文不存在或无机理依据的修辞比喻；
- **禁用未经仪器实测的感官与绝对化二元词**：
  - 无声学计实测禁写“无爆鸣”，无烟气仪实测禁写“无发烟”；
  - 禁写“离火即熄”、“万无一失”、“零失重”、“零恶化”、“零积累”等绝对化表述（除非实验曲线在全量程确证物理零信号，并附误差讨论）。
- **审稿人安全保守措辞**：即使存在正面倾向，仅用“suggests”、“shows potential”、“consistent with”等克制措辞，并将未完全闭环之处如实置于限制说明。

### 2. 样品命名保真与学术引文零虚构
- **严禁擅自更改用户样品命名**：当原始数据或表格列名为 `Sample 1–4`、`Control`、`A`、`B` 等代号时，**绝对只能沿用原始代号**，严禁凭借行业经验推测并强行改写为特定化学配方；仅在用户明确给出映射表后方可更新；
- **引文与图号零虚构**：凡陈述机理依据或绘图惯例来源，所引文献必须在本地 `papers/` PDF 或经查证的联网文献中真实存在，并核准期刊、年份、DOI 与图号，严禁凭记忆拼凑。

### 3. 屏幕正文与演播备忘录（Speaker Notes）物理隔离
- **屏幕肉眼优先**：PPT 屏幕只呈现当前页面图片肉眼可见的物理量与简洁短事实，保证后排投影可读性；
- **SI 与深层机理物理隔离**：未在当前页放主图的支持信息（SI）细节与深层机理阐述，必须写入下方**演播备忘录（Speaker Notes）**，不得作为主图编号直接贴在屏幕卡片里。

### 4. 用户定稿物理只读红线 (User Final Authority)
- 一旦用户声明“PPT 已定稿 / 不要改动内容”，对应 `.pptx` 文件立即降级为**物理只读**；
- 严禁调用任何脚本覆写既有版式或内容，AI 仅保留只读审计与输出修改建议/独立备忘录的权限。
