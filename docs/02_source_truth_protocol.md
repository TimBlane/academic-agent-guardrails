# 支柱二：零幻觉物理文本溯源与数据互锁规范 (Source Truth Protocol)

## 痛点背景
大语言模型在阅读英文论文或提取实验数据时，极容易出现**幻觉性泛化**：
- 凭借模糊的训练集印象或概率预测来脑补数据（如把 0.74 eV 记成 0.38 eV）；
- 伪造带 `Original` 引号的英文引用段落；
- 把横轴循环圈数误读为容量，把库仑效率 99.8% 误读为气凝胶孔隙率；
- 拆散主图子图序号，凭空捏造论文中根本未做过的实验。

---

## 零幻觉三步走法则

### 第一步：物理原文硬提取 (Physical Extraction)
- 在分析任何文献前，必须使用代码工具（如 Python `pymupdf` / `fitz`）将原版 PDF 全文及 Supporting Information 逐页提取为物理文本（`raw_paper_text.txt`）；
- **原话检验红线**：所有标注为原文引述（`Original`）的句子，必须能在 `raw_paper_text.txt` 中进行逐字精确检索（Exact String Match）。未命中的一律判定为模型幻觉，禁止采信。

### 第二步：图表数据“三度交叉核验”
1. **坐标轴极值与物理量单位核准**：
   - 引用任何曲线图前，首先核查横纵坐标轴名称、量纲与范围（例如横坐标是 Cycle 还是 Capacity？终点是 50 还是 150？纵轴是 MPa 还是 GPa？）；
2. **图例与颜色曲线严格对应**：
   - 对应实验组（Sample-A）与对照组（Sample-B）在不同倍率、不同循环节点的真实数值，严禁凭经验混淆；
3. **正文描述与图表标注 100% 互锁**：
   - 正文中的每一个定性或定量结论，必须与图表真实曲线严格吻合。

### 第三步：强制交付事实审计报告 (`ground_truth_audit_report.md`)
- 凡涉及文献深度解读、数据提取或 PPT 生成，必须同步交付事实审计报告；
- 列明汇报中出现的每一个关键参数在原文 PDF 中的具体页码、段落与图表编号；
- 严禁在未经原文字对字核验的情况下向用户宣布“完成”。
