# 支柱三：学术汇报 PPTX 视觉自审与双字体排版规范

## 痛点背景
使用 `python-pptx` 或其他自动化脚本构建幻灯片时，传统的“无头生成”模式极其危险：
- 代码编译无报错并不代表排版视觉合格；
- 文本框随内容长度上下发散膨胀，导致卡片相互重叠、遮挡图片；
- 中英文混杂排版时，全篇由中文字体（如微软雅黑）硬渲染英文字母与阿拉伯数字，极为业余；
- 化学式与离子平铺直写（如 `CO2`、`Li+`），缺乏学术界起码的专业感。

---

## 防御性排版与自审规范

### 1. 交付前真机视觉自审原则（严禁将用户当测试员）
- **绝不允许代码编译通过就直接宣布“完成”**；
- 生成 PPTX 后，必须先调用本地 PowerPoint COM 自动化脚本（`scripts/export_slides.ps1`）将每一页导出为高清 PNG 图片；
- 智能体自身必须调用图片查看工具对每一页进行**像素级肉眼复核**，确认无任何文本溢出、无任何卡片重叠、无任何图文遮挡后，方可向用户汇报交付。

### 2. 双字体独立映射机制（中西文双字体分离准则）
- **英文与数字一律采用 Times New Roman**：所有英文单词、专业术语、单位、化学式、缩写、物理量符号（如 $E_a$、$t_{\mathrm{Li}^+}$、$\mathrm{mAh/g}$）以及所有阿拉伯数字，一律统一使用学术界标准衬线字体 **Times New Roman**；
- **中文字体统一采用高辨识度黑体**：正文与标题汉字统一采用 **微软雅黑**（或思源黑体）；
- **底层 OpenXML 声明**：通过 `apply_dual_fonts.py` 在底层的 Run 属性中显式声明：
  ```xml
  <a:rPr ...>
      <a:latin typeface="Times New Roman"/>
      <a:ea typeface="微软雅黑"/>
  </a:rPr>
  ```

### 3. 化学式与科学记数法规范上下标
- **化学计量数下标**：$\mathrm{CO_2}$、$\mathrm{H_2CO_3}$、$\mathrm{Li_3N}$、$\mathrm{Li_2CO_3}$ 等原子计量数必须严格使用下标；
- **离子电荷数上标**：$\mathrm{Li}^+$、$\mathrm{TFSI}^-$、$\mathrm{Zn^{2+}}$ 等离子符号电荷必须严格使用上标；
- **指数与数量级**：$10^{-4}$ 绝不可写作 `10^-4`，$\mathrm{cm}^{-1}$ 绝不可写作 `cm-1`。

### 4. 几何容器防御性设计
- 优先采用标准的平直纯白矩形（`MSO_SHAPE.RECTANGLE`），边框统一微灰（`#CFD8DC`），严禁使用边界难以预测的圆角矩形；
- 文本框必须显式声明垂直顶部对齐（`tf.vertical_anchor = MSO_ANCHOR.TOP`）；
- 容器必须保留至少 20%~30% 的纵向白边呼吸感，严禁文字填满卡片底部。
